# レベルアイコン（tier1〜tier23）

`public/level_icon/` に置かれた元画像（透過済みのシート）から
`scripts/slice_level_icons.py` で自動スライスした個別アイコンです。
レベルに応じて表示されます。

段位は「区間名＋その中での序数（Ⅰ〜Ⅳ）」で呼びます。例えば tier6〜8 は
ゴールドなので、順に ゴールド Ⅰ / Ⅱ / Ⅲ。チャンピオンだけは tier19〜22 の
4段あるので チャンピオン Ⅳ まであります。頂点の キング（tier23）だけは
序数を持ちません。

エフェクトは **累計300時間 ＝ プラチナ Ⅰ（tier9）から** 付きます。そこから
上は全段に「その金属の光沢」が付き、段が上がるほどオーラ・光輪・舞う粒が
増えて、キングで全虹（最大演出）になります。演出の中身は
`src/lib/level.ts` の `LEVEL_FX`、描画は `src/components/LevelIcon.tsx`。

レベルは累計学習時間から決まります（`hoursToReach(level) = 0.03 × (level-1)²`、
`src/lib/level.ts`）。下の表はその式での目安です。

- レベルに上限は無いので `tier23.png` は Lv317 以降ずっと使われます（永遠の頂点）。
- tier9 以降は「1段に必要な時間が毎段ちょっとずつ増える」形（+139h → +241h）に
  してあります。ずっと加速させると頂点が到達不能になるので、増え方は一定です。
- 区切り（minLevel）・段位名・色・エフェクトは `src/lib/level.ts` の
  `LEVEL_TIERS` と `LEVEL_FX` で調整できます。
- 元画像を差し替えたら `python3 scripts/slice_level_icons.py` で再スライス
  してください（`SHEETS` の並び順がそのまま tier の順番です）。
